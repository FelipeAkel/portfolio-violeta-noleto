# Portfólio Violêta Nolêto

Versão estática do projeto `portfolio-violeta-noleto`, criada com HTML, CSS, JavaScript e Bootstrap 5.

## Abrir no VS Code

1. Extraia o arquivo ZIP.
2. Abra a pasta extraída no VS Code.
3. Abra `index.html` no navegador ou utilize a extensão **Live Server**.

## Estrutura

- `index.html`: estrutura e textos fixos;
- `css/style.css`: cores, layout e responsividade;
- `js/script.js`: destaques, cursos, depoimentos, contatos e interações;
- `assets/images`: imagens do projeto correto;
- `assets/vendor`: Bootstrap 5 incluído localmente.

Os dados que mudam com frequência estão concentrados no início de `js/script.js`.
